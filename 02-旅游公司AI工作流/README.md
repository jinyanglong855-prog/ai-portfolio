# 案例 02 · 旅游咨询公司 AI 工作流（企业交付 · 约 2 周）

## 背景
某旅游咨询公司需要持续获取旅游热点内容用于业务参考，此前依赖人工收集，效率低且不稳定。

## 技术方案
- 飞书自动化：定时定点抓取旅游热点，结构化写入飞书多维表格
- Claude 智能体 + Skill：内容整理与分发的自动化链路

## 我做了什么
- 独立完成需求梳理、方案设计、开发与交付（约两周）
- 面对模糊需求，先对齐"要什么、给谁用、什么频率"，再落地为定时任务+智能体流水线

## 结果
- 企业内实际运行的自动化工作流，替代人工收集环节
