# 案例 01 · 嵌入式 AI 车牌识别系统（毕业设计）

## 背景
面向嵌入式设备的中文车牌检测与识别系统，从零完成模型选型、训练、部署与调优。

## 技术方案
- 检测：YOLOv8（车牌定位）
- 识别：LPRNet（车牌字符序列识别）
- 部署：嵌入式开发板（教师提供的硬件平台），在板端完成推理验证

## 我做了什么
- 完成数据准备、两阶段模型（检测+识别）的训练与联调
- 在开发板上部署推理链路并调通端到端流水线

## 结果
- 端到端可运行的检测+识别 demo
- 完成毕业设计答辩
